首个正式版本：使用 Shizuku 查看并切换默认密码管理器，无需 root。

- 自动发现当前用户已安装的凭据提供者与自动填充服务，可在应用中直接选择。
- 显示首选/已启用凭据提供者和自动填充服务，独立或同时修改。
- 写入前确认与保存备份、写入后读回核对、失败尽力回滚、一键恢复上次配置。
- Material 3 原生中文界面，动态配色、明暗主题、服务搜索。
- GitHub Release 自动更新检查和手动检查。

需要 Android 14+ 和已启动、已授权的 Shizuku。下载 APK 后按系统提示安装。SHA-256 文件可用于检查下载完整性。

本版本的设置读回检查不代表所有 HyperOS 固件或第三方应用均可成功创建通行密钥；请在自己的设备与目标应用中验证实际效果。
